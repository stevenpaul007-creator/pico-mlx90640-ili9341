# PICO-MLX90640-ILI9341

基于 **Raspberry Pi Pico** 的 **MLX90640** 红外热像仪（32×24 像素）实时显示系统，通过 **ILI9341** 显示屏（SPI 接口）输出图像，并利用双核处理与 DMA 加速实现流畅刷新。

## ✨ 特性

- 读取 MLX90640 传感器（32×24 原始像素）
- **双线性插值** 放大至 256×96 像素，平滑显示效果
- **动态温度范围** 自动计算每一帧的最小/最大值，并支持手动调整色标范围
- **右侧 64×240 垂直彩虹色条**（通过 `camColors` 颜色表实现）
- **屏幕底部信息栏**：最高温度、最低温度、中心点温度、电池电压
- **双核分工**：
  - Core 0：屏幕刷新、串口通信、按键检测
  - Core 1：传感器数据读取、插值计算、帧缓冲区生成（使用 DMA 加速的 TFT_eSPI）
- 按键功能：温度范围调整、画面冻结、一键进入 Bootloader 模式

## 🧰 硬件需求

| 组件               | 型号 / 说明                           |
| ------------------ | ------------------------------------- |
| 主控板             | Raspberry Pi Pico / Pico W            |
| 红外热像传感器     | MLX90640（I²C 接口）                  |
| 显示屏             | ILI9341 驱动 SPI 接口 TFT（240×320）  |
| 按键               | 3 个（SEL / 右 / 左）                 |
| 电池               | 可选，用于显示电压（通过 VSYS 测量）   |

## 🔌 接线说明

### MLX90640（I²C 接口）

| MLX90640 | Pico 引脚 |
| -------- | --------- |
| VDD      | 3.3V      |
| GND      | GND       |
| SCL      | GPIO 11   |
| SDA      | GPIO 10   |

### ILI9341 显示屏（SPI 接口，使用 SPI1）

根据项目专属的 `tft_setup.h` 配置文件，引脚定义如下：

| ILI9341 信号 | Pico 引脚 | 说明           |
| ------------ | --------- | -------------- |
| VCC          | 3.3V/5V   | 模块供电       |
| GND          | GND       | 地             |
| CS           | GPIO 4    | 片选           |
| RESET        | GPIO 8    | 复位           |
| DC           | GPIO 7    | 数据/命令选择  |
| MOSI         | GPIO 3    | SPI1 主出从入  |
| SCK          | GPIO 2    | SPI1 时钟      |
| LED          | 3.3V/PWM  | 背光（可选）   |
| MISO         | 不连接    | 仅写显示时未用 |

> 此配置使用 **SPI1** 并启用 **DMA 传输**，与 MLX90640 的 I²C 引脚（GPIO 10/11）无冲突。

### 按键

| 按键功能         | Pico 引脚 | 触发方式 | 说明                         |
| ---------------- | --------- | -------- | ---------------------------- |
| SEL（Bootloader）| GPIO 16   | 下降沿   | 单击或长按重启进入烧录模式   |
| 右键（温度范围） | GPIO 17   | 下降沿   | 增加色标最大温度（+10℃ 循环）|
| 左键（画面冻结） | GPIO 18   | 下降沿   | 冻结/解冻当前画面            |

## 🎮 使用方法

1. 上电后，TFT 屏幕显示初始化和欢迎信息。
2. MLX90640 开始采集数据（默认刷新率 4Hz）。
3. 屏幕显示热像图，底部显示：
   - **MAX**：当前帧最高温度（℃）
   - **MIN**：当前帧最低温度（℃）
   - **CEN**：中心附近点温度
   - **BAT**：电池电压（V）
4. 右侧垂直彩虹条表示温度到颜色的映射。

## 🔘 按键操作

| 按键       | 短按效果                                                     |
| ---------- | ------------------------------------------------------------ |
| **SEL**    | 立即重启并进入 **USB Bootloader 模式**，方便烧录新固件       |
| **右键**   | 增加色标的 **最大温度范围**（每次 +10℃），循环切换（默认 50℃，最大 100℃） |
| **左键**   | **冻结/解冻** 画面，冻结时显示停止更新但后台继续采集         |

## ⚙️ 代码结构说明

- **Core 0**（`setup`/`loop`）：
  - 初始化按键中断、TFT、MLX90640 和电池服务
  - 主循环等待 Core 1 通过 FIFO 发送数据就绪信号
  - 调用 `spr.pushSprite(0, 0)` 刷新显示
  - 处理串口命令（发送 `'r'` 重启至 Bootloader）

- **Core 1**（`setup1`/`loop1` → `core1_entry`）：
  - 循环读取 MLX90640 一帧数据（32×24 浮点温度）
  - 可选：若冻结标志为真，跳过后续处理
  - 将温度放大 10 倍转为整型，计算 min/max
  - 双线性插值缩放至 256×96（实际写入 320×240 离屏精灵）
  - 温度映射到 0~1023 再转为颜色表索引，绘制像素
  - 在精灵上叠加文本信息（温度极值、中心点、电池电压）
  - 通过 `rp2040.fifo.push_nb()` 通知 Core 0 刷新

- **中断服务**：
  - `enterBootloader()`：重启进入烧录模式
  - `buttonRightPressed()`：标记温度范围调整请求
  - `buttonLeftPressed()`：切换冻结标志

## 📝 注意事项

- MLX90640 刷新率不宜过高（代码中设为 4Hz），否则 I²C 可能读取失败。
- 浮点运算较多，建议编译优化级别 `-O2`。
- 当前实现中，Core 1 写入离屏精灵 `spr`，Core 0 直接刷新该精灵，存在潜在的竞争条件。建议后续改进为双缓冲区或通过 FIFO 传递帧数据。
- 如果屏幕显示异常，请检查：
  - TFT 与 Pico 的接线是否与 `tft_setup.h` 完全一致
  - SPI 频率是否过高（可尝试降至 20MHz）
  - 是否启用了 DMA（`USE_DMA_TRANSFERS` 需要库支持）
- 电池电压测量需要 Pico 的 VSYS 引脚供电且硬件分压正常（默认 3:1）。
